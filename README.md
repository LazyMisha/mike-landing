# Mike's Landing Page

Personal portfolio for Mykhailo Trunov, built with Next.js.

Live: https://mike-landing-swart.vercel.app

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run test -- --run
npm run lint
npm run typecheck
npm run build
```
